# claude-skills

Personal agent skills for physical fabrication and 3D design.

## Language

**Skill**: A slash command + SKILL.md pair that instructs Claude Code how to approach a category of task.

**Parametric design**: A 3D model defined by named variables so dimensions can be changed without remodelling.

**Press fit / snap fit**: Assembly method using material flex — no screws. Press fit = constant friction; snap fit = locking undercut.

**FDM constraints**: Physical limits of fused-deposition 3D printing — overhang angle ≤ 45°, min wall 1.2 mm, bridge span ≤ 20 mm.
